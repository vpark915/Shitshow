How to add one:
- Drop the file in Assets/Sounds. WAV preferred, mono, short; it should start right on the sound
  (no silence at the start). Claude can trim it for you.
- Add its credit to "attribution texts.txt" (CC BY sounds must be credited in the game).
- Put it in its slot in Assets/Resources/SoundBank (the name in the first column below). Several clips in one slot =
  one picked at random each time.
- Slots marked (hook) also need a line of code to play them: ask Claude to wire them up.

* = get these first.   "x3" = how many variations to get.
